01 · UrbanArena

A city that behaves
like a city.

UrbanArena turns official territory-wide 3D geospatial resources into a continuously rendered world an agent can physically inhabit.

Cities test more than visual recognition. Street appearance, road topology, physical accessibility, time, weather, and moving people all refer to the same geographic system. An agent must keep those views aligned while acting over long horizons.

UrbanArena streams georegistered 3D Tiles into Unity and aligns them with Hong Kong's pedestrian network. A model-agnostic interface exposes first-person perception, physical control, and map interaction without privileged coordinates or simulator state.

01

Geographic foundation

Territory-scale 3D city assets and a pedestrian network remain registered to the same real-world coordinates.

02

Interactive embodiment

First-person vision, physical movement, and an overhead map form one closed-loop action space.

03

Living conditions

Clock, illumination, weather, road closures, and pedestrians alter an episode without changing its geography.

Built with the 3D Visualisation Map and 3D Pedestrian Network released by the Lands Department of the Government of the Hong Kong SAR.

02 · UrbanBench

Urban agency,
level by level.

Thirteen task types trace a deliberate progression from local understanding to explicit navigation, implicit goals, multi-stop planning, and replanning in a changing city.

L1

Understand

Read the immediate urban scene and acquire missing evidence through movement.

  • VR Visual recognition
  • OU Orientation
  • AEQ Active exploration QA
L2

Navigate

Translate goals, routes, and instructions into physically valid movement.

  • SGN Short-range navigation
  • LGN Long-range navigation
  • IN Instruction following
  • CN Constrained navigation
L3

Infer

Discover where to go when the destination is described only by intent or evidence.

  • PTS Place search
  • III Implicit intent
L4

Plan

Coordinate several destinations while preserving order, timing, and route efficiency.

  • TWS Time windows
  • MSP Multi-stop planning
L5

Adapt

Revise a route when streets close and move safely around dynamic pedestrians.

  • DCR Dynamic closure
  • NP Pedestrian navigation

03 · Evaluation protocol

The model sees what
the agent sees.

Every model receives the same first-person observation, task instruction, action schema, and stopping criteria. No hidden position, remaining-distance signal, or privileged simulator state is exposed.

Fixed interaction horizon 100 steps

Each episode records the full action and geographic trajectory for diagnostic analysis.
